## 작동 방식

1. Check whether Microsoft Teams is running.
2. Send `NUMLOCK` twice.
3. Wait 60 seconds.
4. Repeat until PowerShell closes or the universe does.

```powershell
.\TeamsAntiAFK.ps1
```
