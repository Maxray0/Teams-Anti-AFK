## What is this?

A tiny PowerShell script that checks whether Microsoft Teams is running and presses **Num Lock** twice every minute. No mouse tourism, no mysterious software, just enterprise-grade keyboard abuse.

## Features

- 100% PowerShell
- No installation required
- Coffee-break compatible
- Protects the precious green status indicator™
- Repeats until the heat death of the universe

## How it works

1. Check whether Microsoft Teams is running.
2. Send `NUMLOCK` twice.
3. Wait 60 seconds.
4. Repeat until PowerShell closes or the universe does.

```powershell
.\TeamsAntiAFK.ps1
```

## Why?

“Away” does not mean “lazy”. It may mean writing documentation, solving problems, using another PC, thinking, making coffee, or simply existing as a human being.

## 🔒 Security

- VULN-2026-0001: The script presses Num Lock. Status: known and intentional.
- VULN-2026-0002: The README may consume more memory than the script. Status: will not fix.
- VULN-2026-0003: A green dot may be mistaken for productivity. Status: industry-wide issue; no patch available.

Threat model: humans, keyboards, coffee, and Microsoft Teams. Everything else is out of scope.

Responsible disclosure: take a breath, remember that the script presses Num Lock, reassess the severity, then open an issue if humanity is still in danger.
