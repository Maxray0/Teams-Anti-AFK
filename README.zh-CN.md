## 这是什么？

PowerShell、Microsoft Teams、**Num Lock** 和 60 秒。鼠标不乱跑，只有企业级键盘滥用。

## 功能

- 100% PowerShell
- 无需安装
- 兼容咖啡时间
- 守护珍贵的绿色状态指示器™
- 重复运行直到宇宙热寂

## 工作原理

1. 检查 Microsoft Teams 是否正在运行。
2. 连续按两次 `NUMLOCK`。
3. 等待 60 秒。
4. 重复执行，直到 PowerShell 关闭，或者宇宙先关机。

```powershell
.\TeamsAntiAFK.ps1
```

## 为什么？

“离开”不等于“偷懒”：也许正在写文档、排查问题、思考或冲咖啡。
